Typing Challenge Game

Test your typing speed, accuracy and keyboard skills in two fun modes.

CLO4 • HTML5 • CSS3 • JavaScript • Bootstrap
Difficulty changes speed, number of bubbles, targets and time limit.

Mode A: Bubbles

Letter Recognition

  • At least 5 bubbles rise at the same time
  • Press the matching letter before it crosses the red miss line
  • Correct = +10, Wrong key = -5, 6 misses = Game Over
  • Win: pop 20 (Easy) / 30 (Medium) / 40 (Hard) bubbles
  • Every 10 pops, bubbles get faster and one extra bubble appears

Mode B: KeyMagnet

Keyboard Precision

  • One target key is shown at a time, from a real key array
  • Use your keyboard or tap the on-screen keys
  • Correct = +10, Wrong key = -5
  • Win: 15 targets in 60s (Easy) / 20 in 45s (Medium) / 25 in 30s (Hard), else Time Up
  • Correct, wrong and response time are all tracked

Rule: Score never goes below 0. Restart and Reset work without reloading the page.
